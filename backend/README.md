# Backend

NestJS checkout API. See the [repo root README](../README.md) for architecture, setup, environment variables, and deployment.

Quick reference:

```bash
npm install
npm run seed        # dummy products
npm run start:dev   # http://localhost:3000
npm run test:cov
```
